## 1. AUDIT DE L'EXISTANT (REPRISE DES CONTENUS)

L'analyse minutieuse du site actuel [mariage-madagascar.com](https://www.mariage-madagascar.com/) a permis de cartographier et de récupérer l'ensemble des contenus clés à préserver, moderniser, corriger de leurs coquilles et optimiser pour le SEO.

### 1.1 Destinations Auditées & Contenus Clés
*   **Nosy Be ("L'île aux Parfums")** :
    *   *Attraits* : Nosy Iranja (langue de sable blanc reliant Iranja Be et Iranja Kely, eaux turquoise), Nosy Tanikely (aquarium naturel marin), plage d'Ambatoloaka (mondialement connue, propice à tous thèmes et budgets), Cascade sacrée entourée de végétation tropicale.
    *   *Logistique Europe* : Vol Paris -> Saint-Denis (Réunion) -> Nosy Be (avec Air France, Air Austral, NeosAir), ou escale à Antananarivo.
    *   *Logistique USA* : Transit obligatoire via la France (Paris), puis vol vers Nosy Be avec escale à la Réunion.
    *   *Transports alternatifs* : Depuis Antananarivo, Majunga ou Diego-Suarez par vols directs, ou par voie terrestre (taxi-brousse / location) jusqu'à Ambanja, puis transfert maritime depuis le port d'Ankify (29 km d'Ambanja) vers Nosy Be.
*   **Sainte-Marie (Nosy Boraha)** :
    *   *Attraits* : Ambiance authentique, calme, intime et romantique loin du tourisme de masse. Plages de sable blanc, lagon turquoise, cimetière des pirates historique. Observation des baleines à bosse de juin à septembre (spectacle naturel unique pour un mariage).
    *   *Logistique Europe & USA* : Transit par Antananarivo (TNR). Vol international via Air France, Turkish Airlines, Ethiopian Airlines, Kenya Airways. Puis vol intérieur TNR -> Sainte-Marie (SMS) avec Madagascar Airlines (Tsaradia) (environ 1h15).
    *   *Alternative terrestre/maritime* : Route Antananarivo -> Tamatave / Toamasina (8h de route), puis bateau de Tamatave ou Soanierana-Ivongo vers Sainte-Marie (2 à 4h de traversée).
*   **Tuléar (Ambatomilo)** :
    *   *Attraits* : Récif de corail spectaculaire, plages sauvages et immaculées bordées de palmiers. Immersion culturelle avec les ethnies Vezo et Mahafaly (musique traditionnelle, rituels symboliques).
    *   *Logistique* : Vol vers Antananarivo, puis vol domestique vers Tuléar (TLE) avec Madagascar Airlines / Tsaradia (1h30). Option terrestre par la RN7 (2 jours de route à travers les paysages typiques des Hauts Plateaux et du Sud, avec halte).
*   **Antananarivo (La Capitale)** :
    *   *Attraits* : Ville historique nichée sur les collines des Hauts Plateaux. Rova de Manjakamiadana, églises coloniales, marché d'Analakely. Climat tempéré, réceptions élégantes ( Carlton, Colbert, domaines privés), cuisine raffinée (ravitoto, romazava) et traditions (lamba, musiciens de Hira Gasy).

### 3.1 Tables d'utilisateurs et rôles (1-7)

#### 1. `users` (Table d'authentification gérée par Supabase Auth)
*   `id` : `uuid` PRIMARY KEY
*   `email` : `varchar` UNIQUE NOT NULL
*   `created_at` : `timestamp with time zone` DEFAULT `now()`

#### 2. `profiles` (Informations communes d'identité et de rôle)
*   `id` : `uuid` PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE
*   `first_name` : `varchar` NOT NULL
*   `last_name` : `varchar` NOT NULL
*   `phone` : `varchar`
*   `role` : `varchar` NOT NULL CHECK (role IN ('super_admin', 'admin', 'commercial', 'wedding_planner', 'travel_planner', 'accounting', 'support', 'provider', 'client'))
*   `avatar_url` : `text`
*   `language_preference` : `varchar` DEFAULT 'fr'
*   `currency_preference` : `varchar` DEFAULT 'EUR'
*   `created_at` : `timestamp with time zone` DEFAULT `now()`
*   `updated_at` : `timestamp with time zone` DEFAULT `now()`

#### 3. `couples` (Espace spécifique pour les futurs mariés)
*   `id` : `uuid` PRIMARY KEY DEFAULT `gen_random_uuid()`
*   `partner_1_profile_id` : `uuid` NOT NULL REFERENCES profiles(id)
*   `partner_2_profile_id` : `uuid` REFERENCES profiles(id)
*   `wedding_date` : `date`
*   `estimated_budget` : `decimal(12,2)`
*   `created_at` : `timestamp with time zone` DEFAULT `now()`

#### 4. `team_members` (Membres de l'équipe interne Mariage Madagascar)
*   `id` : `uuid` PRIMARY KEY DEFAULT `gen_random_uuid()`
*   `profile_id` : `uuid` NOT NULL REFERENCES profiles(id) UNIQUE
*   `job_title` : `varchar` NOT NULL
*   `specialty` : `varchar`
*   `bio` : `text`
*   `whatsapp_link` : `varchar`
*   `is_active` : `boolean` DEFAULT true

#### 5. `providers` (Informations légales et fiches des prestataires externes)
*   `id` : `uuid` PRIMARY KEY DEFAULT `gen_random_uuid()`
*   `profile_id` : `uuid` NOT NULL REFERENCES profiles(id) UNIQUE
*   `company_name` : `varchar` NOT NULL
*   `legal_registration` : `varchar`
*   `tax_id` : `varchar`
*   `address` : `text`
*   `website` : `varchar`
*   `commission_rate` : `decimal(5,2)` DEFAULT 15.00
*   `is_validated_by_admin` : `boolean` DEFAULT false
*   `validated_at` : `timestamp with time zone`
*   `created_at` : `timestamp with time zone` DEFAULT `now()`

#### 6. `provider_services` (Liaison entre prestataires et catégories de services)
*   `id` : `uuid` PRIMARY KEY DEFAULT `gen_random_uuid()`
*   `provider_id` : `uuid` NOT NULL REFERENCES providers(id) ON DELETE CASCADE
*   `service_category` : `varchar` NOT NULL CHECK (service_category IN ('accommodation', 'catering', 'photography', 'decoration', 'music', 'beauty', 'transport', 'activity', 'wedding_planning', 'gifts'))
*   `description` : `text`
*   `base_price` : `decimal(10,2)`

#### 7. `leads` (Fiches CRM des prospects non encore convertis)
*   `id` : `uuid` PRIMARY KEY DEFAULT `gen_random_uuid()`
*   `first_name` : `varchar` NOT NULL
*   `last_name` : `varchar` NOT NULL
*   `email` : `varchar` NOT NULL
*   `phone` : `varchar`
*   `project_type` : `varchar` NOT NULL CHECK (project_type IN ('honeymoon', 'proposal', 'wedding', 'vows_renewal', 'anniversary', 'romantic_escape', 'dinner', 'other'))
*   `destination_id` : `uuid`
*   `target_date` : `date`
*   `budget_range` : `varchar`
*   `guests_count` : `integer` DEFAULT 2
*   `lead_source` : `varchar`
*   `status` : `varchar` DEFAULT 'new' CHECK (status IN ('new', 'contacted', 'qualified', 'meeting_scheduled', 'proposal_sent', 'follow_up', 'proposal_accepted', 'deposit_paid', 'confirmed', 'in_preparation', 'completed', 'review_requested', 'lost_cancelled'))
*   `assigned_to` : `uuid` REFERENCES profiles(id)
*   `created_at` : `timestamp with time zone` DEFAULT `now()`

### 3.9 Règles d'accès (RLS) et Sécurité de la Base de Données
Pour garantir une parfaite confidentialité et conformité RGPD, Supabase RLS (Row Level Security) est activé sur l'ensemble des tables :
1.  **Profils d'utilisateurs (`profiles`)** :
    *   `SELECT` : Un utilisateur connecté peut lire son propre profil. Les administrateurs peuvent lire tous les profils.
    *   `UPDATE` : L'utilisateur ne peut mettre à jour que ses propres données de profil (hors champ de rôle, réservé aux admins).
2.  **Prestataires (`providers`)** :
    *   `SELECT` : Public pour les prestataires validés. Un prestataire peut consulter sa fiche complète (validée ou non).
    *   `INSERT`/`UPDATE` : Uniquement modifiable par le prestataire associé ou un administrateur.
3.  **Clients et Couples (`couples`, `clients`)** :
    *   `SELECT` : Uniquement visible par les deux partenaires associés et les rôles de l'équipe interne (wedding_planner, commercial, admin).
4.  **Réservations et Devis (`bookings`, `proposals`, `contracts`)** :
    *   `SELECT`/`UPDATE` : Limité à l'utilisateur client propriétaire et à l'équipe administrative de Mariage Madagascar.
    *   Les prestataires (`providers`) ont accès uniquement aux lignes de réservation (`booking_items`) et de commission qui les concernent directement (`provider_id = auth.uid()`).
5.  **Administration et Logs (`activity_logs`)** :
    *   Accès réservé uniquement aux rôles `super_admin` et `admin`.
